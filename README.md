# FactuPerú

Facturación electrónica SUNAT, punto de venta, caja e inventario que se instala en la computadora del negocio y funciona sin internet.

- **Página:** https://rcesarvillalobosp-sys.github.io/factuperu/
- **Descargar para Windows:** [última versión](https://github.com/rcesarvillalobosp-sys/factuperu/releases/latest)

Este repositorio contiene solo la página web y los instaladores publicados.
